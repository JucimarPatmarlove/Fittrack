# Triage Labels

The five canonical labels (strings equal their names):

| Role | Label |
|------|-------|
| needs-triage | `needs-triage` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

Create missing labels with: `gh label create "needs-triage" "needs-info" "ready-for-agent" "ready-for-human" "wontfix" --repo JucimarPatmarlove/Fittrack`
